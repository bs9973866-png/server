# Paper Minecraft Server 26.2

Готовый набор файлов для запуска **Paper 26.2 на Windows 10/11**.

## Что нужно

- 64-битная Java 25 или новее.
- Windows 10/11.
- Интернет для первой загрузки Paper и городской карты.

## Запуск

1. Открой репозиторий и нажми **Code → Download ZIP**.
2. Распакуй ZIP в обычную папку, например `C:\MinecraftServer`.
3. Запусти `START-SERVER.bat`.
4. При первом запуске скрипт автоматически скачает Paper 26.2 и проверит SHA-256.
5. До запуска Minecraft автоматически скачивается и устанавливается карта Нижнего Манхэттена 1:1.
6. Сервер остановится, пока ты не прочитаешь и не примешь [Minecraft EULA](https://aka.ms/MinecraftEULA): для этого нужно вручную изменить `eula=false` на `eula=true` в `eula.txt`, затем снова запустить `START-SERVER.bat`.

Для отдельной загрузки Paper можно запустить `DOWNLOAD-PAPER.bat`.

## NEW YORK RP

- Плагин экономики и городского меню собирается через GitHub Actions.
- Человеческие NPC устанавливаются отдельным NPC Plugin: скины, редактор, пути и действия по ПКМ.
- Автомобили устанавливаются отдельным Mercedex Car Plugin: модели, четыре места и ресурспак.
- Установка этих двух аддонов: запусти `INSTALL-RP-ADDONS.bat` при выключенном сервере.
- Инструкция по NPC и автомобилям: [roleplay/ADDONS.md](roleplay/ADDONS.md).
- Карта **NEW YORK — Lower Manhattan 1:1 scale NYC** автоматически устанавливается при первом запуске; отдельная ручная распаковка не нужна. Подробности и авторство: [INSTALL-CITY-WORLD.md](INSTALL-CITY-WORLD.md) и [MAP-CREDITS.txt](MAP-CREDITS.txt).

После установки аддонов скачай свежий артефакт `NewYorkRP-Paper-26.2` из [GitHub Actions](https://github.com/bs9973866-png/server/actions) и положи `NewYorkRP.jar` в `plugins/`.

**Важно:** не оставляй старые версии NewYorkRP в `plugins/`. Сделай резервную копию мира перед заменой карты.

## Настройки

- `server.properties` — основные настройки сервера.
- `plugins\` — папка для совместимых серверных плагинов.
- `eula.txt` — принятие соглашения Minecraft.

В стартовом файле выделяется до 4 ГБ оперативной памяти. Не выделяй серверу всю память компьютера.

## Подключение

- На том же компьютере: `localhost`.
- В одной локальной сети: локальный IPv4-адрес компьютера с сервером.
- Подключение из интернета требует отдельной настройки сети и роутера. Не публикуй свой публичный IP в открытом доступе.

## Важно

- Перед обновлением сервера делай резервную копию папок миров.
- Не пытайся открывать мир новой версии на старой версии Minecraft.
- Серверный JAR и архив карты не хранятся в GitHub: карта загружается автоматически из оригинального источника на первом запуске.
- Используй только плагины, которые заявляют поддержку Paper 26.2, и проверяй их происхождение.

Официальная документация: [PaperMC Downloads Service](https://docs.papermc.io/misc/downloads-service/).
