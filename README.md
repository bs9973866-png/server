# Spigot Minecraft Server 26.2

Готовый набор файлов для сборки и запуска **Spigot 26.2 на Windows 10/11**.

> Важно: Spigot распространяется через официальный BuildTools. Поэтому сам серверный JAR не хранится в этом репозитории — он собирается на твоём компьютере.

## Что понадобится

- 64-битная **Java 25 или новее** (JDK).
- Интернет-соединение.
- Windows 10/11.

BuildTools автоматически скачает необходимые исходники и соберёт `spigot-26.2.jar`.

## Быстрый запуск

1. Нажми **Code → Download ZIP** и распакуй архив в папку без кириллицы и необычных символов, например `C:\MinecraftServer`.
2. Установи 64-битную Java 25 или новее.
3. Запусти `BUILD-SPIGOT.bat`.
4. Дождись окончания сборки.
5. Запусти `START-SERVER.bat`.
6. При первом запуске сервер остановится, если EULA ещё не принята.
7. Прочитай [Minecraft EULA](https://aka.ms/MinecraftEULA). Если согласен, открой `eula.txt` и измени `eula=false` на `eula=true`.
8. Запусти `START-SERVER.bat` снова.

## Подключение

- На компьютере с сервером: `localhost`
- В одной Wi-Fi/LAN сети: локальный IPv4-адрес компьютера с сервером.
- Для игры через интернет потребуется отдельная настройка сети и роутера. Не публикуй свой публичный IP в открытом доступе.

## Настройки

Основные параметры находятся в `server.properties`. Порт по умолчанию — `25565`, онлайн-проверка включена (`online-mode=true`).

Плагины Bukkit/Spigot помещай в папку `plugins`, затем перезапускай сервер.

## Оперативная память

В `START-SERVER.bat` серверу выделяется до 4 ГБ RAM. Если меняешь значения `-Xms` и `-Xmx`, оставляй достаточно памяти Windows и другим программам.

## Важно

- Не загружай в GitHub папки мира, логи, личные конфиги и серверный JAR.
- Перед обновлением версии делай резервную копию мира.
- Не открывай мир, созданный в новой версии, старой версией Minecraft.
- Сборка выполняется официальным способом через [Spigot BuildTools](https://www.spigotmc.org/wiki/buildtools/).
