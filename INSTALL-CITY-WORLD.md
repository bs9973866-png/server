# Городская карта сервера NEW YORK RP

Архив карты хранится в самом репозитории: `maps/new-york-midtown-manhattan.zip`. Отдельно скачивать карту с посторонних сайтов или вручную распаковывать её не нужно.

## Какая карта используется

**Midtown Manhattan, New York City**, автор BasVerhagen. Карта включает сотни зданий, станции метро, вокзал, театры, кинотеатры, конгресс-холлы, парки и оформленные небоскрёбы. Оригинальная страница указывает Minecraft Java 1.18.2; архив версии 2.9 опубликован в ZIP и имеет размер около 64.5 МБ.

Оригинальная страница и авторство:
https://www.minecraftmaps.com/49807-midtown-manhattan-new-york-city

## Установка

1. Скачай ZIP всего репозитория через **Code → Download ZIP**.
2. Распакуй его.
3. Прими Minecraft EULA в `eula.txt`.
4. Запусти `START-SERVER.bat`.

При первом запуске скрипт проверит архив из папки `maps`, найдёт `level.dat` и установит мир как `world`. Существующий мир не перезаписывается. Если архив отсутствует или повреждён, сервер остановится с понятной ошибкой вместо создания случайного мира.

## Совместимость и атрибуция

Карта изначально опубликована для Java Edition 1.18.2 (архив v2.9). Paper 26.2 может обновить формат мира при первом запуске. Сделай резервную копию перед обновлением. Автор карты — BasVerhagen; сохраняй авторство и оригинальную ссылку. Карта не создана командой NEW YORK RP.
