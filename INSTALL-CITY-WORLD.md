# Установка большой карты Нью-Йорка

Для сервера выбрана карта **New York City от ArnisWeb — 20 км²**. Она собрана по OpenStreetMap: улицы, кварталы, здания, парки и вода. Это не вручную нарисованные интерьеры — многие здания являются внешними оболочками, их можно будет дорабатывать для RP.

**Страница карты:** https://arnisweb.com/minecraft-city-maps

На странице выбери New York City → Java Edition → Download. На момент подготовки страницы карта отмечена как временно бесплатная; сайт может попросить аккаунт. Сам архив привязан к загрузке сайта, поэтому он не включён в GitHub-репозиторий.

## Установка на Paper

1. Полностью останови сервер.
2. Сделай копию папок `world`, `world_nether` и `world_the_end`. Не удаляй резервную копию.
3. Распакуй скачанный ZIP. Найди папку, внутри которой прямо лежит `level.dat`.
4. Переименуй папку карты в `world` и положи её рядом с `server.properties`, заменив старый `world` только после резервного копирования.
5. Старые `world_nether` и `world_the_end` тоже перенеси в резервную копию, чтобы сервер создал измерения заново для новой карты.
6. Проверь в `server.properties`, что стоит `level-name=world`.
7. Запусти сервер и проверь спавн. Если точка появления неудачная, администратор может встать в нужное место и выполнить `/setworldspawn`.

Карта указана как Java 1.21.4; Paper 26.2 должен обновить данные мира при первом запуске. Поэтому резервная копия обязательна. Большой мир может сначала загружаться дольше обычного.
